# Script reference

**Audience:** contributors and operators who run, review, or change a script.

Every script that exists under `scripts/` is listed. Parameters are transcribed from each script's `param`
block or argument parser, including type, default, and whether the parameter is mandatory. `[switch]`
parameters default to `$false` (PowerShell) or are absent unless stated (shell).

`M` marks a mandatory parameter. PowerShell scripts run with `Set-StrictMode -Version Latest` and
`$ErrorActionPreference = 'Stop'`: a thrown error ends the script with a non-zero exit code, so only the
distinct `exit` codes below are called out.

Not catalogued here: `build/linux-firecracker/provision-guest.sh`,
`build/windows-hyperv/provision-guest.sh`, and `build/windows-hyperv/user-data.pkrtpl`, which build the guest
image rather than the product; they are covered by
[30-workloads/06-guest-images.md](../30-workloads/06-guest-images.md). The systemd units
`scripts/linux/csweet-office-*.service` and the launchd plists `scripts/macos/com.csweet.office.*.plist` are
configuration templates, not scripts; their values are in [configuration.md](configuration.md).
