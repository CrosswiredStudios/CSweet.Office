Download **the file ending in `-test-setup.exe`** under Assets and open it on a fresh Windows x64 test PC. The EXE downloads and verifies the matching MSI. Double-clicking the MSI directly also opens **C-Sweet Office Setup**. You can return to the wizard from Start by opening **C-Sweet Office (Windows test)**.

1. Use a Windows edition that supports Hyper-V, with virtualization enabled in firmware, administrator access, an internet connection and at least 64 GiB free on the system drive for preparation. Allow additional space for your chosen Office allocations.
2. Choose **Install** in the wizard and approve the administrator prompt. Setup shows progress while downloading the guest and checking Hyper-V. If it requests a restart, save your work, restart Windows and reopen **C-Sweet Office (Windows test)** from Start.
3. Choose **Open Office** when setup finishes. In the Office page, choose managed or private Headquarters. Use a compatible test Headquarters and approve the named PC. Return to Office to choose resource limits and install the services. Check Device health and the matching Office in Headquarters.

These Windows installer files are unsigned test builds. Windows may show **Unknown publisher**. The release includes SHA-256 checksums. The installer verifies the signed development manifest and guest downloads. The destination PC certifies the guest before pairing. For an enrolled test PC, drain the Office in Headquarters and wait for active assignments to finish before uninstalling **C-Sweet Office (Windows test)** in Windows Settings.
