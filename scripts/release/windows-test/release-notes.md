Download **the file ending in `-setup.exe`** under Assets and open it on a Windows x64 PC. The EXE downloads and verifies the matching MSI. Double-clicking the MSI directly also opens **C-Sweet Office Setup**. You can return to the wizard from Start by opening **C-Sweet Office**.

1. Use a Windows edition that supports Hyper-V, with virtualization enabled in firmware, administrator access, an internet connection and at least 64 GiB free on the system drive for preparation. Allow additional space for your chosen Office allocations.
2. Choose **Install** in the wizard and approve the administrator prompt. Setup shows progress while downloading the guest and checking Hyper-V. If it requests a restart, save your work, restart Windows and reopen **C-Sweet Office** from Start.
3. Choose **Open Office** when setup finishes. In the Office page, choose managed or private Headquarters. Use a compatible Headquarters and approve the named PC. Return to Office to choose resource limits and install the services. Check Device health and the matching Office in Headquarters.

This Windows preview is unsigned. Windows may show **Unknown publisher**. The release includes SHA-256 checksums. The installer verifies the signed development manifest and guest downloads. The destination PC certifies the guest before pairing. For an enrolled PC, drain the Office in Headquarters and wait for active assignments to finish before uninstalling **C-Sweet Office** in Windows Settings.
