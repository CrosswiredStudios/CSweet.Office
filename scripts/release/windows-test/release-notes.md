Download **the file ending in `-test-setup.exe`** under Assets and open it on a fresh Windows x64 test PC. The EXE downloads and verifies the matching MSI. You can also install the MSI directly and open **C-Sweet Office (Windows test)** from Start.

1. Use a Windows edition that supports Hyper-V, with virtualization enabled in firmware, administrator access, an internet connection and at least 64 GiB free on the system drive for preparation. Allow additional space for your chosen Office allocations.
2. Approve Windows setup and choose to prepare the computer. It downloads the versioned development guest bundle and tests Hyper-V locally. If Windows requests a restart, reopen **C-Sweet Office (Windows test)** from Start afterward.
3. When the Office page opens, choose managed or private Headquarters. Use a compatible test Headquarters and approve the named PC. Return to Office to choose resource limits and install the services. Check Device health and the matching Office in Headquarters.

These Windows installer files are unsigned test builds. Windows may show **Unknown publisher**. The release includes SHA-256 checksums. The installer verifies the signed development manifest and guest downloads. The destination PC certifies the guest before pairing. For an enrolled test PC, drain the Office in Headquarters and wait for active assignments to finish before uninstalling **C-Sweet Office (Windows test)** in Windows Settings.
