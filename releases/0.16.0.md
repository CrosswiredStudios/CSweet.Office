# Office 0.16.0

Windows Maintenance verifies the release manifest against the publisher pinned at install before preparing an automatic update. A source-checkout update cannot enter Maintenance. Windows MSI layouts distribute large certified guest images in signed external cabinets and verify the reconstructed image before installation.

For a first install with Headquarters, the Office MSI can enroll from administrator-provisioned machine settings and a one-use enrollment token. The combined installer supplies the token after database migration. Enrollment retains the existing machine identity checks and configured resource limits.
