# Office 0.16.1

After losing a VM creation response, the Windows Office can recover the existing
instance using the signed Headquarters request. RuntimeHost checks the original
assignment, fencing epoch, specification and lease. The Hyper-V helper checks the
VM identity, private disks and network isolation before returning the handle.

Maintenance verifies Windows update certification before draining workloads.
Windows Maintenance can authenticate with a recovered Office certificate when it
claims a repair or upgrade from Headquarters. This fixes a TLS failure that could
leave an approved request waiting until it expired.
The combined installer reports Office enrollment failures in the Windows
Application log under `CSweet.Office.Setup`, including failures followed by MSI rollback.
