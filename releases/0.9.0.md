# 0.9.0

Adds reviewed runtime public internet transport over guest protocol 1.1, retaining hardware-isolated VMs without hypervisor network adapters. Office validates public destinations and scopes bounded TCP/UDP sockets to the authenticated assignment lifetime. Restricted/build workloads retain protocol 1.0 compatibility.

Adds pinned development payloads with Node 22/npm, .NET 10, Python 3.12 and native build tools, plus a real-provider internet/dependency certification mode for Hyper-V, Firecracker and Apple Virtualization. Provider support remains false without matching v15 evidence. Office Contracts is 0.10.0.

Local builds/tests are not real-provider certification. Destination-host certification, image installation and live-agent recovery remain rollout requirements.

Adds an explicit IPv4-only certification and signed policy mode for hosts without public IPv6 connectivity. IPv6 remains unavailable until full hardware evidence passes; limited evidence cannot authorize full network policies.
