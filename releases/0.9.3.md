# 0.9.3

Fix two successive failures in hosted Office installation. The certification host
now accepts the authenticated `runtime.logs` diagnostic snapshots emitted during
dependency checks, instead of stopping with `The guest sent an unsupported broker
message.` The stream remains ordered and bounded, with only an 8 KiB tail retained;
other streams, malformed envelopes and invalid sequences remain rejected.

The hosted image builder now sets `/etc/resolv.conf` to Office's disposable
`/run/csweet/resolv.conf` after libguestfs customization has finished, and verifies
the link before exporting the VHDX. Setting it inside the provisioning command was
undone by libguestfs's resolver restoration. The published 0.9.2 image retained
Ubuntu's systemd stub link, so npm failed DNS lookup with `EAI_AGAIN` even though
direct public DNS packets succeeded.

Diagnostics do not count as a certification report or successful completion. The
probe report, successful guest exit, required network/development checks and egress
cleanup remain mandatory (SEC-INV-10). Failed internet certification includes the
retained guest diagnostic tail; unsupported messages identify their body type.
Timed-out dependency commands now retain bounded stdout/stderr and identify their
arguments instead of discarding the cause as `TaskCanceledException`.

Office.Contracts remains 0.10.0. Local authenticated-protocol and command-timeout
regressions and all 237 Office tests pass with sibling Office.Contracts references
disabled.

Real Hyper-V verification on October 15 at 18:14 Pacific passed the full
`csweet-hardware-vm-smoke-v15-ipv4` suite using the corrected host/probe and a separate
copy of the published 0.9.2 image with its DNS link corrected. Its guest digest is
`sha256:48c8cb2be86c4b724c95bdff6b75bd7c28c1cde11099de70a05a06d01fe4736d`.
Isolation, brokered builds, npm install/ci/test/build, portable tools, public TCP/UDP,
denied private/host access and lease cleanup passed. IPv6 remains unavailable under
this mode. The CI-built 0.9.3 release and its normal installation certification remain
release/rollout steps.
