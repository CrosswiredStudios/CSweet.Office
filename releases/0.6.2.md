# Office 0.6.2

- Let verified hosted Windows bundles proceed directly to host certification without waiting on the source-build mutex. The bundle already contains the Office binaries and guest image, so this path performs no source compilation or image construction.
- Reserve source-build coordination and its progress wording for the explicit source fallback path. Prebuilt setup now reports certification, signing, packaging, and installation phases without claiming another Office build is required.

Target-host certification and local development signing remain mandatory. Office.Contracts remains pinned to 0.7.1. Existing Offices must be drained with no active assignments before upgrading.
