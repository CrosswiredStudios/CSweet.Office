# Office 0.6.0

- Tagged releases now build Windows x64 and Ubuntu Linux x64 development bundles on GitHub-hosted runners. Bundles contain self-contained Office binaries, certification tools, and prebuilt guests. No signing secrets or sibling repository checkout are needed by that workflow.
- Windows assisted onboarding in the matching C-Sweet update checks tagged releases before building local source. It verifies archive sizes, SHA-256 hashes, and extraction paths. Missing/unreachable releases can use the configured local checkout; failed integrity checks stop setup.
- Each destination host still runs real Hyper-V/KVM isolation certification and creates its own development guest-image signature. These are development bundles, not production-signed installers or CI-certified providers.
- The existing production signing pipeline remains available through manual dispatch on hardened runners.

Deploy the C-Sweet onboarding changes with this release. Keep the published Office.Contracts 0.7.0 pin; no contracts package change is required. Existing Offices still need to be drained with no active work before upgrade.
