# Office 0.6.1

- Restore execute permission on every Linux Office executable and guest probe after downloading GitHub Actions artifacts. Names such as `CSweet.Office.Node` contain dots and were incorrectly skipped in 0.6.0, preventing the bundled certification runner from starting.
- Check executable permissions in the extracted Linux release tarball before publication, while keeping configuration files non-executable. Missing binaries or permission-setting failures stop packaging.

Use this release for Linux prebuilt installation. Bundles still require real target-host certification and local development signing. Office.Contracts remains pinned to 0.7.1. Existing Offices must be drained with no active assignments before upgrading.
