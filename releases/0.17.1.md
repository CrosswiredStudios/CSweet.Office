# Office 0.17.1

Windows setup now packages the release-approved Linux compute disk alongside the agent disk. Fresh assisted installations can reserve a workspace for an eligible business from the capacity selected at setup. The combined installer can read the signed Office MSI's image catalog when preparing the Headquarters configuration.

New hosted development bundles carry a stable public update certificate and a signed bootstrap manifest. Existing installations need an already-trusted publisher to accept an unattended update.
