# Office 0.17.0

- An enrolled Windows Office can provision ephemeral Linux x64 workspaces on Hyper-V through its installed RuntimeHost service. Each VM has zero network adapters. Office reports it ready after the compute service inside that guest answers a challenge over a Hyper-V socket.
- Compute is off by default. To enable it, include the signed compute VHDX alongside the certified Office agent image. In the combined install's protected `office.json`, select the business and reserve CPU, memory, disk and a maximum number of environments. Leave capacity for agent workloads. Configure Headquarters to approve the same compute image digest for that business.
- Office retains operation receipts across restarts so Headquarters can recover results after a lost acknowledgment. If a guest command may already have run, Office can report its outcome as unknown. This lets the operator reconcile the result without automatically repeating the command.
- Use Headquarters with Office compute support and `CSweet.Office.Contracts` 0.14.1. For separate deployments, update Headquarters first. Before upgrading an existing Office, drain it and wait for active assignments to reach zero.
