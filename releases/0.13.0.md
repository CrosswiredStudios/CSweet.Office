# Office 0.13.0

- Fresh installations can use a chosen fixed local volume for Office service binaries, images,
  VM disks, caches, and mutable state. Windows assisted setup carries the reviewed destination
  through the authenticated preflight/redemption; portable installers prompt on the target host.
- Saved installation locations are used by recovery, maintenance, repair, updates, and removal.
  Existing installations retain their destination; moving an installed Office is not included.
- Windows services and Unix service startup verify the selected storage before running. Missing,
  replaced, removable, read-only, or otherwise unsuitable storage is refused.
- Office.Contracts is pinned to 0.12.0. Headquarters must use the matching contracts and apply its
  `AddOfficeInstallationStorage` migration before offering the new assisted selection flow.

Native platform packaging/signing and second-volume install/reboot/workload/update/uninstall
acceptance remain release requirements. Source builds and resolver tests do not certify an installer
or deploy this change to an installed Office.
