# Office 0.18.0

- Upgrade Headquarters first, then drain the Office and use the identity-preserving Office upgrade.
- Stopping a workspace VM returns its running capacity and retains its disk. Starting it checks the current Office budget.
- To resize an existing Windows Office partition, supply `-WorkspaceCpuCount`, `-WorkspaceMemoryMiB` and `-WorkspaceDiskMiB` to `Install-CSweetOfficeRuntimeHost.ps1` during an identity-preserving upgrade. The installer divides the existing machine allocation between workspace VMs and agent runtimes.
