# Office 0.5.0

- Adds an independent Windows recovery service managed through C-Sweet. It accepts only administrator-authorized repair requests for its enrolled Office, over an authenticated outbound connection.
- Repairs check local work before and after stopping dispatch, then preserve the Office identity and settings while reinstalling the verified local payload. A signed newer recovery package supplies an updated payload.
- The recovery app supports guided repair of an expired connection and separately authorized removal and fresh enrollment. Older installations require the current recovery package and Windows administrator approval once.
- Installation registers automatic recovery-service startup and restart. Uninstallation removes that service too.
- No arbitrary remote commands, unattended removal, or unsigned remote payload downloads are supported.
