# Office 0.19.1

- Windows Setup continues when the only sign of an earlier installation is an empty Office data folder. If Setup finds earlier Office files or a service, it identifies the blocker.
- If Hyper-V certification fails, choose **Open setup log** to read the preserved log. Public internet checks now record whether a connection failed during TCP connect or the TLS handshake.
- Requires Office.Contracts 0.15.0 and compatible Headquarters and account services for Office-first linking.
